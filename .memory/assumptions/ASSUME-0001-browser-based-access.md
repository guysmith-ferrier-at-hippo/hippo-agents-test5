## Assumption Description
Users access the digital service through modern web browsers on mobile phones, tablets, and desktop workstations. The service does not require native mobile applications.

## Context & Rationale
Analysis of UK public sector user patterns shows that responsive web applications satisfy user needs across devices without the maintenance overhead of native mobile applications.

## Impact If Wrong
If native mobile applications are required, the project team must build and maintain separate iOS and Android client applications.

## Validation Method
Monitor web access logs and analytics during the Alpha and Beta phases to evaluate device distributions and user completion rates.
